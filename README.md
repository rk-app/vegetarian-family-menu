# Ontario Vegetarian Family Menu

Private family meal-planning site: a 4-week ovo-vegetarian menu for two adults and a ~3-year-old in Ontario (eggs + dairy, no allergies).

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```
